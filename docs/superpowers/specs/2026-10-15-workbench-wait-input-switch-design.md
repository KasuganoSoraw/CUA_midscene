# 工作台等待配置与运行时输入开关

## 范围

界面修改限于 `execution/review/web` 的任务检查页面。使用本地 Vue 与 CSS、系统字体和仓库中的 UCD 素材，不引入 UI 框架，不实现 GDEClaw 外层导航，不修改执行器协议。

## 等待配置

视觉依据为 `UCD设计/等待选项/index.html` 及其 `assets`。动作类型和动作前等待位于第一行；等待触发条件和等待时长位于第二行，等宽左右排列，窄屏上下排列。SVG 按 HTML 引用位置匹配，只复制工作台实际使用的素材。

等待触发条件映射到 `aiWaitFor`。等待时长以毫秒表示条件满足前的最长等待时间，映射到 `timeout`，不是固定暂停时间。界面通过字段提示明确这一语义，保留现有数值校验和动作前等待字段。

设计稿中的示例步骤、示例数值和录制截图不成为任务数据。定位参考图的使用范围仍限于单击和双击动作。

## 运行时输入开关

输入文本动作中的“允许运行时输入”文字左对齐，开关紧邻其右侧，替代复选框。开关外观参考 `UCD设计/大图/表单替换项.svg`：轨道 38×20 像素、圆形滑块 16 像素；开启为蓝色并将滑块置右，关闭为中性灰并将滑块置左。点击区域高度至少 32 像素。

采用可交互的 `button` 和本地 CSS 实现两种状态，提供 `role="switch"`、可访问名称、`aria-checked`、键盘操作、焦点与禁用态，不把静态 SVG 当作完整交互控件。

开关直接绑定现有 `editor.parameterized`。开启显示输入标签、录制默认值和参数说明；关闭显示固定输入值。沿用现有字段保留、草稿恢复及任务保存行为，不引入新资产或确认弹窗。

## 保存与异常

编辑自动保存为浏览器草稿，明确保存后才写入任务资产。保持现有版本冲突检查、保存校验和错误提示。忙碌、只读和高级编辑状态下，开关遵循现有禁用条件。

## 验证与交付

验证开关的两态、禁用、键盘操作、草稿恢复，以及运行时参数与固定值的既有序列化契约。验证等待条件和超时的往返转换、响应式布局与 SVG 加载。运行类型检查、相关测试与前端构建，并在本地页面核对效果。

等待配置与素材调整、运行时输入开关分别提交，提交描述使用中文。仅提交本次范围内的源码、测试及设计说明。
