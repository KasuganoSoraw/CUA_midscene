# CUA 工作台操作指南

工作台用于教系统完成电脑操作，并在正式使用前检查和试运行。它从 GDEClaw 的设置入口打开，不需要在对话中请求启动，也不需要普通用户配置运行环境。

## 三个页签

| 页签 | 用途 |
| --- | --- |
| 流程录制 | 演示操作，选中录制并生成可复用任务 |
| 任务检查 | 核对并调整步骤、输入参数和定位参考图 |
| 任务调试 | 用本次参数试运行，查看结果和执行报告 |

每条录制生成一个独立 Skill。左侧直接列出任务，没有场景分组，不需要发布或同步。

## 一次完整旅程

1. 打开目标应用，完成登录，停在流程开始的位置。
2. 在“流程录制”选择屏幕，点击“准备录制”。
3. 切换到目标应用，点击桌面悬浮条的开始图标，或按 Ctrl+Shift+F9。
4. 演示一项完整工作，尽量避免无关点击和窗口切换。
5. 点击悬浮条的停止图标，或再次按快捷键，等待保存。
6. 返回工作台选中录制，点击“生成任务”。
7. 系统自动归纳任务名称、描述和目标，完成后进入“任务检查”。
8. 核对步骤与参数，保存，再进入“任务调试”试运行。

录制保存视频和键鼠记录；生成任务把演示整理成可编辑步骤，不会再次操作业务系统。生成完成不表示每一步都理解准确，应先复核。生成期间可以切换页签，返回后仍显示状态；不要结束 GDEClaw 或工作台服务。

## 录制与生成

一次录制只演示一件完整的事情，明确开始和结束位置。优先使用测试数据，不录入真实密码；画面、文本和操作会留在录制中。

准备状态尚未开始录制，可使用悬浮条的放弃图标取消。开始后显示计时和停止图标，网页也有停止控制。

录制列表中的视频与操作日志卡片可打开对应文件夹，卡片不是播放器。点击“生成任务”即可，不需要填写名称、场景或目标。名称由系统归纳；同名冲突时不会覆盖已有任务，请查看提示并联系维护人员处理。

## 检查步骤

选择左侧任务，逐步核对右侧动作类型、目标描述、等待条件和截图。完整截图用于了解页面，局部截图用于辨认本次操作的位置。没有独立录制证据的手工步骤显示占位图，不借用其他步骤截图。

可新增、删除或拖动排序步骤。描述应说明页面中的目标，如“订单号标签右侧的输入框”，不要使用固定坐标。

定位参考图帮助系统理解目标外观，不是固定点击坐标。点击类动作可上传或更换图片，并使用开关启用或停用；输入文本等不适用的动作不会提供此功能。

输入文本可启用“允许运行时输入”：输入标签告诉使用者应填什么，录制默认值提供初始内容，说明用于补充约束。关闭后使用步骤内的固定文本。

“动作前等待”是操作前暂停；等待动作的“最长等待时间”是等待条件满足的上限，不是无条件暂停。

## 保存与草稿

编辑会暂存在当前浏览器，点击“保存”才写入正式任务。关闭或刷新前应保存。浏览器草稿不是正式备份。

其他工具同时修改任务时会提示冲突。先保留需要的内容，再使用重新加载入口读取正式文件；不要反复保存来覆盖外部修改。

删除任务会删除对应的正式 CUA Skill，请谨慎确认。删除原始录制不会删除已生成任务，反之亦然。运行中的任务不能删除。

## 试运行与报告

任务调试默认使用自适应运行 guided，根据录制步骤适应当前页面；只有需要严格按保存步骤回放时才选择 replay。调试参数只用于本次运行，不改写保存的默认值。

开始运行后切回目标应用，倒计时结束后不要同时操作鼠标键盘。取消准备不会执行操作；运行中可停止任务，但停止不能撤销已经发生的业务操作。

成功、失败和主动停止都有结果提示。可用时点击“查看执行报告”打开报告；技术详情用于维护人员排查。执行器完成不等于业务结果一定正确，请结合目标页面与报告核对。失败不会自动重试。

“复制运行指令”会复制任务身份、运行方式和电脑操控插件链接。你需要自行粘贴到 GDEClaw 对话中，工作台不会自动发送。复制内容不包含本次调试参数。

没有任务时可从零录制。目录未配置、任务资产异常、报告不可用或无法生成时，保留提示并联系维护人员，不需要自行修改 JSON 或程序。
