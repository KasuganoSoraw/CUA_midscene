## ADDED Requirements

### Requirement: 任务运行工作区
系统 SHALL 提供独立的“任务运行”工作区，允许用户选择场景、canonical 任务以及逐步执行或整体规划模式，并根据任务清单中的输入定义呈现运行时输入表单及默认值。

#### Scenario: 选择任务并填写输入
- **WHEN** 用户在任务运行页选择一个包含输入定义的任务
- **THEN** 系统展示对应的输入字段、标签、说明和默认值，并允许本次运行覆盖这些值

#### Scenario: 选择执行模式
- **WHEN** 用户选择逐步执行或整体规划并启动任务
- **THEN** 系统分别使用现有 `task run` 或 `act run` 语义执行所选 canonical 任务

### Requirement: 只执行已保存任务
系统 MUST 仅按场景和任务标识解析并执行磁盘上的 canonical 任务，不得直接执行尚未保存的浏览器草稿。

#### Scenario: 从脏草稿请求运行
- **WHEN** 用户从存在未保存修改的可写任务点击运行入口
- **THEN** 系统先成功保存该任务，再打开运行页并选中保存后的任务

#### Scenario: 保存失败
- **WHEN** 用户从存在未保存修改的任务点击运行入口且保存失败
- **THEN** 系统保留复核页及草稿，不得启动任务执行

### Requirement: 可取消的服务端准备阶段
系统 SHALL 在接受启动请求后进入由服务端持有的准备倒计时，并 SHALL 允许用户在实际执行开始前取消。

#### Scenario: 倒计时后开始执行
- **WHEN** 有效启动请求进入准备状态且倒计时正常结束
- **THEN** 系统启动任务子进程并将会话状态更新为运行中

#### Scenario: 准备期取消
- **WHEN** 用户在准备倒计时期间请求停止
- **THEN** 系统取消待启动任务且不得创建执行子进程

#### Scenario: 页面刷新
- **WHEN** 浏览器在准备或运行期间刷新并重新查询状态
- **THEN** 系统返回服务端持有的当前会话及时间信息

### Requirement: 单执行会话管理
系统 MUST 在同一 review server 进程中最多允许一个处于准备、运行或停止中的任务执行会话。

#### Scenario: 重复启动
- **WHEN** 已有任务处于准备、运行或停止状态时收到新的启动请求
- **THEN** 系统拒绝新请求且不影响现有会话

#### Scenario: 终态后重新运行
- **WHEN** 前一会话已成功或失败且用户启动新任务
- **THEN** 系统允许新会话覆盖此前的终态展示

### Requirement: 复用现有 CLI 子进程
系统 SHALL 通过无 shell 的 Node 子进程调用项目现有 CLI，并 SHALL 以独立参数传递场景、任务、数据目录、模式及运行时输入。

#### Scenario: 源码环境启动
- **WHEN** server 运行在包含源码 CLI 与项目内 `tsx` 的开发环境
- **THEN** 系统使用当前 Node 运行时和项目内 `tsx` 启动源码 CLI

#### Scenario: 构建环境启动
- **WHEN** server 运行在仅包含已构建 CLI 的交付环境
- **THEN** 系统使用当前 Node 运行时启动构建后的 CLI 文件

#### Scenario: CLI 不可用
- **WHEN** 支持的源码和构建 CLI 入口均不存在
- **THEN** 系统拒绝启动并返回可诊断的错误，不得进入虚假的运行状态

### Requirement: 执行状态和结果可观察
系统 SHALL 提供可轮询的执行状态，包含阶段、所选任务、模式和相关时间；运行期间 SHALL 展示真实已用时间，终态 SHALL 展示结果或错误摘要，并在可用时展示 run directory。

#### Scenario: 长时间没有输出
- **WHEN** 执行子进程长时间未产生标准输出但仍未退出
- **THEN** 系统继续报告运行中及真实已用时间，不得伪造步骤完成百分比

#### Scenario: 成功完成
- **WHEN** CLI 以零退出码结束且最终 JSON 表明 executor 成功
- **THEN** 系统报告成功并展示最终结果和 run directory

#### Scenario: 执行失败
- **WHEN** CLI 退出码非零、最终结果为失败或最终 JSON 无法解析
- **THEN** 系统报告失败并展示经过限长处理的诊断信息

#### Scenario: 状态隐私
- **WHEN** 任意客户端查询当前执行状态
- **THEN** 响应不得回显本次运行的输入值

### Requirement: 停止正在运行的任务
系统 SHALL 允许用户请求停止正在运行的任务子进程，并 SHALL 将停止过程反映在会话状态中。

#### Scenario: 停止运行中任务
- **WHEN** 用户对运行中的任务请求停止
- **THEN** 系统进入停止状态、终止受管子进程，并最终报告该运行未成功完成
